# Motorola Tweak Mod (MockingBat)

An all-in-one customization Xposed / LSPosed module designed for Motorola devices (Hello UI), inspired by LuckyTool.

## ✨ Key Features

### 🎨 UI & Visual Effects
* **Liquid Glass & Frosted Glass UI:** Apply sleek Liquid Glass and Frosted Glass blur effects across the entire system UI.
* **Control Center Tweaks:** Customize Quick Settings / Control Center layout, tiles, and visual elements.
* **Notification Bar & Center:** Modify status bar icons, notification panel behavior, and appearance.
* **Lock Screen Customizations:** Tweak lock screen layout, shortcuts, and visual styles.

### 🏠 Home Screen (Launcher)
* **Grid Adjustments:** Freely customize home screen and app drawer grid sizes, icon layouts, and spacing.

### 🛠️ System & Security Tweaks
* **CorePatch Integration:** Bypass signature verification to allow app downgrades and installing modified APKs.
* **Disable FLAG_SECURE:** Allow screenshots and screen recording in secure apps that normally block them.
* **Disable Camera Shutter Sound:** Force disable the mandatory camera shutter sound on region-locked devices.
* **Auto Update Checker:** Built-in update detection to keep the module up to date.
* *...and many more tweaks!*
